🚀 CÁCH SỬ DỤNG
═══════════════════════════════════════════════════════════════════════════════

1. Bắt đầu Backend:
   cd backend
   python app.py

2. Bắt đầu Frontend (terminal mới):
   cd frontend
   npm install (lần đầu)
   npm start

3. Truy cập:
   http://localhost:3000

4. Thử nghiệm:
   - Nhập nguyên liệu → Xem gợi ý
   - Nhập tên món → Xem nguyên liệu
   - Admin tab → Thêm/sửa/xóa luật
